# 实体手机与模拟器验收计划

## 素材和预期投影

运行 `./scripts/generate-test-media.ps1`（Node.js + FFmpeg）。所有素材为原创程序图案 / 正弦波。

- `equirect-180.mp4`：正方形 180° 经纬源，上左黄、上右绿、下左红紫、下右蓝，中心白色方块，15° 经纬网格。
- `fisheye-180.mp4`：同一方向场的等距圆形鱼眼源。选择鱼眼后应与经纬源的观看方向一致，中心白、上黄绿、下红紫蓝；不是显示原始圆图。
- `sbs-fisheye-180.mp4`：左右眼并排，右眼交换红蓝分量；手动选左右眼应改变颜色，不能同时显示两个圆。
- `grid-360.mp4`：2:1 测试图，选择 360° 后横向可持续环绕；不得把 180° 文件当 360°。
- `tone.mp3`：6 秒 660 Hz；`embedded-subtitles.mp4`：MP4 内嵌 mov_text 字幕。
- `sample.srt/vtt/ass/ssa`：0.5–2 秒与 2.5–4.5 秒测试文本。

代码中 `ProjectionMath.cameraAngles` 对所有视野角点约束半球前向；单元测试覆盖纵横屏比例、FOV 极值与边界转动。仪器测试读取截图像素检查经纬与鱼眼上下方向。人工进一步确认没有镜像、无效黑边、跳变和接缝。

## 自动测试

```powershell
.\gradlew.bat testDebugUnitTest lintDebug
.\gradlew.bat connectedDebugAndroidTest
```

仪器测试包含本地视频与音乐解码、四个渲染模式切换、180° 投影像素方向、四种字幕连续导入和关闭、内嵌文本与延时、常亮标记、十次 Android power sleep / wake 事件、无自动恢复、Activity 重建、横竖屏、进入后台、Room 读写 / Migration、SAF 不支持持久授权的副本回退。测试通过 Android shell 产生实际系统关屏事件，不伪造受保护广播。

自动测试通过不代表所有实体手机、电源键、传感器或蓝牙已通过。通过报告见 VALIDATION.md。

## A–J 最高优先级验收（每种目标实体手机均执行）

记录品牌 / 型号 / Android 版本 / APK SHA-256、素材、屏幕超时时间、测试结果和日志。将系统超时设为 15 或 30 秒，用列表循环使素材播放至少超时两倍；测试结束恢复原系统设置。应用代码不修改超时。

|编号|操作|通过条件|
|---|---|---|
|A|普通 MP4 无触摸连续播放|超过系统超时仍亮，音画继续|
|B|180° 两种声明投影分别连续播放|同 A，转动与拖动不会停止常亮|
|C|360° 连续播放|同 A，连续水平环绕|
|D|音乐连续播放|屏幕保持亮|
|E|四种播放状态分别按实体电源键|正常锁屏，声音立即停止，位置保存|
|F|E 后解锁并返回应用|保持非播放，手动点播放才恢复原位置|
|G|暂停播放后等待|KEEP_SCREEN_ON 取消，系统可正常熄屏|
|H|播放时切换另一 App / 按 Home|无后台声音；返回不自动播|
|I|每轮手动播放，然后锁屏、解锁，共 10 次|不崩溃、不黑屏、不自播、位置合理|
|J|蓝牙耳机播放音乐后锁屏|耳机停止收到音频；解锁仍停止|

可辅助记录：`adb logcat`、`adb shell dumpsys power`、`adb shell dumpsys window`、`adb shell dumpsys media.audio_flinger`。实体电源键与不同 OEM 派发顺序必须人工验证；若出现延迟，保存系统日志与音频录制证据。

## 其他操作

1. 使用系统文件选择器多选视频与音乐；停止后杀进程，重新打开确认历史 / 收藏 / 模式 / 字幕 / FOV / 位置保留。
2. SAF 测试本机 Downloads、文档提供方、不可持久化提供方；撤销权限 / 删除文件后确认错误可见并能移除失效记录。
3. 外部字幕导入 UTF-8 BOM、UTF-16、GB18030，损坏时间戳、空文件、无权限、超过 8 MB；失败时视频继续，旧字幕不错误残留。
4. 连续切换字幕、内嵌轨道、关闭字幕，调整毫秒偏移、字号 / 颜色 / 背景 / 描边 / 间距，检查屏幕字幕不随全景旋转，横竖屏不被控制栏遮挡。
5. 全景拖动和双指缩放；操作进度条 / 菜单不得改变视角，锁定后不能误触播放。
6. 开关传感器、横竖屏、复位；比较手持转动和画面方向，确认无方向反转 / 突然跳变。不具备传感器的设备应该显示提示，触摸仍可用。
7. 用已知支持 / 不支持的 AVC、HEVC、VP9、AV1、HDR、4K/8K 样本试播。记录具体解码器与错误；不支持时应提示，不崩溃。当前渲染器不保证 HDR 色彩。
8. 有线耳机拔出、蓝牙断开、来电 / 其他音频应用抢焦点；检查暂停与恢复策略不会绕过锁屏停止。
9. 打开带内嵌封面的音乐，确认名称 / 歌手 / 封面；创建两个播放列表并检验上 / 下、随机、单曲 / 全部循环。
10. 连续快速切换模式至少 30 次，重建 Activity、前后台切换，记录解码与 GL 错误，检查只有一个播放器输出音频。
